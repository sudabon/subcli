# Spec Delta

## Purpose

公式 CLI のヘッドレス出力を統一イベント形式へ正規化し、長大行・エラー出力・シグナル終了・タイムアウト・終了コード伝播を安全に処理する子プロセス実行基盤と、オフライン検証用偽 CLI ハーネスの要件を定義する。

## ADDED Requirements

### Requirement: 正規化イベントスキーマと前方互換性
システムは、各公式 CLI の構造化ストリーム出力を `session_started`, `text`, `tool_call`, `tool_result`, `usage`, `completed`, `error`, `unknown` のいずれかの種別を持つ正規化イベントへ変換しなければならない（SHALL）。各イベントはプロバイダ ID、種別、発生時刻、元の JSON 生データ（`raw`）、および種別に応じたセッション ID・テキスト・ツール名・ツール入力・使用量情報（入力トークン数、出力トークン数、任意のコスト）を保持しなければならない（SHALL）。未知のイベント型や未知のフィールドを受信してもエラーで中断してはならず（MUST NOT）、`unknown` 種別として生データを保持して処理を継続しなければならない（SHALL）。

#### Scenario: 未知のイベント型を受信した場合の継続処理
- **WHEN** 公式 CLI の出力ストリームに未定義のイベント型や追加フィールドを含む JSON 行が含まれる
- **THEN** パーサはエラーを返さず、元の JSON を `raw` に保持した `unknown` イベントを生成してストリーム処理を継続する

### Requirement: 長大行対応と stderr 保持を備えた子プロセス実行
システムは公式 CLI を子プロセスとして起動し、プロバイダ固有の環境変数調整を適用したうえで標準出力を 1 行ずつ読み取らなければならない（SHALL）。標準出力の読み取りは長い 1 行（例: 数百 KB を超えるツール出力や JSON）でも行長上限で停止してはならない（MUST NOT）。標準エラー出力は直近 64KB を保持し、エラー終了時に表示およびシークレットマスク済みログへ記録しなければならない（SHALL）。子プロセスの終了コードは `subcli` の終了コードとして伝播させなければならない（SHALL）。

#### Scenario: 64KB を超える長大 JSON 行の読み取り
- **WHEN** 子プロセスが 1 行あたり 1MB 近い NDJSON 行を標準出力へ書き出す
- **THEN** ランナーは行を切り詰めたり停止したりせず、完全な 1 行としてパーサへ渡す

#### Scenario: 子プロセス失敗時の stderr 表示と終了コード伝播
- **WHEN** 子プロセスが標準エラー出力へエラー詳細を出力し終了コード 2 で終了する
- **THEN** ランナーは直近 64KB 以内の stderr をエラー表示およびログ記録に用い、終了コード 2 を呼び出し元へ返す

### Requirement: シグナル転送とタイムアウト制御
システムは、ユーザーからの割り込み（Ctrl+C / SIGINT）またはタイムアウト到達時に、子プロセスグループ全体へ SIGINT を送信し、5 秒以内に終了しなければ SIGTERM、さらに 5 秒以内に終了しなければ SIGKILL で確実に停止させなければならない（SHALL）。

#### Scenario: SIGINT 受信時の段階的シャットダウン
- **WHEN** ヘッドレス実行中に割り込みシグナルまたはタイムアウトが発生し、子プロセスが SIGINT を無視して残存する
- **THEN** ランナーは子プロセスグループへ SIGINT を送り、5 秒後に SIGTERM、さらに 5 秒後に SIGKILL を送って孤児プロセスを残さず終了する

### Requirement: 偽 CLI によるオフライン検証ハーネス
リポジトリは、Phase 0 fixture を再生し遅延・シグナル・終了コード異常を再現できるテスト用偽 CLI（`claude` / `codex` / `agy`）を備え、実 CLI やサブスク認証を使わずにランナーおよびパーサを自動検証できなければならない（SHALL）。

#### Scenario: 偽 CLI を用いたランナーの自動テスト
- **WHEN** テスト用偽 CLI ディレクトリを PATH 先頭に設定してランナーテストを実行する
- **THEN** 実 CLI を起動せずにストリーミング解析、タイムアウト、シグナル転送、および終了コード伝播が検証される
